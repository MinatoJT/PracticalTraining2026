# 软件需求说明（课程裁剪版）

文档编号：PT2026-SRS；版本 0.1；状态：待评审。适用基线与标准边界见 [文档控制](README.md)。

## 1. 范围与来源

目标是在 CRAG-MM 多模态问答框架中完成三个任务，分析数据、实现算法并用多个指标评价。课程资料还要求小组实训报告、源码和个人周报；教师报告模板不在本次新增材料中，本文不能替代它。

来源分为：课程要求（`_course_extract.txt`）、现有接口约束（`agents/base_agent.py`、evaluator）、从当前实现归纳的工程行为。后者尚不是经过项目方批准的新需求。具体代码和验证关联见 [追踪矩阵](traceability.md)。

## 3. 输入、输出与边界

输入图像采用 Pillow Image；问题为字符串；历史为 role/content 等字典构成的列表。官方样本由 iterator 送入，外部调用应遵守 BaseAgent 契约。当前新实现报告 batch size 为 1。

输出公开接口只返回答案字符串，证据 ID、打分与拒答原因通过可选 trace 辅助诊断，不是一个已对外承诺的独立网络 API。数据模型字段见 [设计](design.md)。

Task1 禁用 Web 不等于完全离线：默认模型提供方为远程 API。当前 `NEWAGENTS_ALLOW_STABLE_KNOWLEDGE` 默认开启，允许特定情况下使用模型稳定知识；因此不能宣称所有回答均严格仅来自检索证据。若课程要求严格检索闭环，应评审该配置并增加对照验证；本次不修改默认值。

## 4. 质量目标与验收缺口

课程要求评价准确性、幻觉、缺失及真实性等表现，但未从现有材料确认任何数值通过阈值。禁止填入臆造的准确率、性能或显存保证。建议评审后确定：固定数据分割与版本、样本/轮数、基线对照、指标阈值、模型费用与超时预算、允许的降级行为。

验收前还需：18 个现有离线单测实际结果；真实 Task1–3 样本及失败分类；不同任务误配 agent 的检查；模型服务故障、限流和凭据缺失测试；日志敏感数据检查；目标 Windows UI 构建/运行记录。当前缺口详见 [验证](verification.md)。
